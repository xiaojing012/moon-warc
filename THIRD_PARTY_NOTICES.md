# Third-Party Notices

moon-warc is written in pure MoonBit and depends only on the MoonBit
standard library.

## MoonBit Core Library (`moonbitlang/core`)

This project imports the following packages from the MoonBit core
library, distributed with the MoonBit toolchain
(https://www.moonbitlang.com):

- `moonbitlang/core/buffer`
- `moonbitlang/core/debug`
- `moonbitlang/core/encoding/utf8`
- `moonbitlang/core/env`

MoonBit project and its contributors.

## Specification sources

The implementation follows the WARC 1.1 specification (ISO
28500:2017), publicly maintained by the IIPC (International Internet
Preservation Consortium) at
https://iipc.github.io/warc-specifications/. No specification text is
reproduced in this repository; `docs/specification-map.md` contains
only references and paraphrases.

No other third-party code, data or binaries are used.
